# 课表分享与双人对比

> 2026-10-11 课表对比改为独立界面（不再叠加在主课表上）：好友课表卡片「对比」或课表主页「分享与好友 → 课表对比」进入，返回键/关闭回到来源页。结果网格把每天渲染成「忙碌」「空闲」两种课程卡观感的大框（连续同状态节次合并，课间并入、午休/晚休断开）；时间轴、整点虚线、日分隔线与主课表同一实现。对比范围是纯展示视口：默认覆盖所选课表作息的首节至末节，全部节次始终参与对比。配置面板里组合课表整体出现，课程筛选默认收起并全选。
>
> 2026-10-10 对比界面已重构为语义色+卡片化（深浅模式与全部风格自适应），课表导入入口统一收进「课表管理」，详见 [timetable-display-management.md](timetable-display-management.md)。

在课表主页点击“分享与好友”，可以打开“分享课表 / 生成口令”“导入口令”“好友课表”和“课表对比”；好友课表界面每位好友卡片上也有「对比」入口（自动预选该好友）。对比可选多份我的课表和多位好友，并在每份课表里取消不参与的课程（默认全选；忙闲课表只能整表参与）。共同空闲表示所有选中课表该节都没课；同节有课表示我有课且至少一位好友也有课，详情列出是哪些好友。节次结构不同的课表不能一起加入。不会自动读取剪贴板。分享沿用已有口令和分享身份；对比本身不生成口令。

## 开启与退出

配置面板展示双方作息，只有节次数、顺序以及每节起止时间完全相同才能开启。学校或校区相同不代表兼容；缺失、无效或不同结构不能使用默认作息补齐或自动换算。结构不同仍可分享、导入和独立查看好友课表。

对比在独立界面展示：顶栏显示比较对象与「调整」，周导航按校园时区 Asia/Shanghai 的实际日期切周。网格中每天只渲染两种块：任一参与者有课的连续节次合并为「忙碌」大框，全部无课的连续节次合并为「空闲」大框，观感与主课表课程卡一致；课间空档（≤20 分钟）并入框内，午休/晚休等大间隔（三校区均 ≥50 分钟）断开不覆盖；有效期外或数据缺失的未知节次单独成块，不并入忙碌或空闲；点击块查看双方该时段明细。退出界面不影响主课表的显示和编辑。

对比时间范围是**纯展示视口**：默认覆盖所选课表作息的首节至末节（如 08:30–22:30），可在作息范围内以 5 分钟步进调整；全部节次始终参与对比判定，调整范围只影响网格显示窗口，不会丢数据。范围行实时显示「范围内纳入 N 节」，「重置」一键回到完整作息。

切周按校园时区 Asia/Shanghai 的实际日期重新计算，不把双方各自的第 N 周直接配对。配置保存选定 ID（含组合身份）、视口范围与课程筛选（按课程名+同名序号记忆，好友快照更新后不错位），重建后恢复并重新读取数据；组合成员增删或成员课程变化会在事务内重新解析。来源修改会重新计算；结构变得不兼容、读取失败或对象删除时隐藏旧结果并提示，不能把旧结果继续当作当前结果。

## 判定规则与限制

- 仅比较选定个人课表的课程（CLASS）及好友分享中的课程占用，不包含考试、个人活动或其他个人课表。“共同空闲”仅表示共同无课，不代表没有其他安排。
- 一个作息项就是一节，不自动拆成 45 分钟小节。默认六节为 08:30–10:15、10:30–12:15、14:00–15:45、16:00–17:45、18:45–20:30、20:45–22:30。午休和节间空档不生成比较区域，独立节次不跨休息时间合并。
- 课程与一节有任何正时长交叠，整节即有课；端点相接不算占用。双方这一节都无课显示绿色共同空闲，双方都有课显示红框同节有课，仅一方有课不计入这两类。
- 同节冲突不等于课程实际时间重叠。例如自己 08:30–09:00、好友 09:30–10:00，仍同占第一节。统计为完整节次数及完整节次时长，不是实际课程重叠时长。
- 整节必须完全落在双方有效期内才能判定；部分超出也整节标为未知，不能算空闲。有效期使用已有实际起止边界，不擅自延长结束时间。所有入选节次均未知时提示当前周不在双方共同有效期内。
- 作息外课程按原始时间展示，作息外部分不参与节次对照，也不生成额外节次。有效个人课表没有课程可以对比；非法记录或读取失败不能当作空课表。
- 支持完整课表和仅忙闲分享。仅忙闲好友只显示占用，不显示或推断课程名称、地点。比较结果不写入个人课程、日程或提醒，不创建分享身份，不改变 HITA1 协议和数据库版本。

分享、已保存好友读取和本地比较可以离线使用。好友数据是已保存快照，不是联网实时同步；好友的新安排需要重新导入更新。

## 2026-10-11 审查修复轮

系统性审查确认并修复：

- 选中 ID 曾用空串拼接，任何正常 UUID 选择都会被拆成单字符（P1）：改为非空共享分隔符并转义。
- 畸形本地课程（end≤start，含被排除课程）原先被过滤前置校验绕过，畸形课表会显示成全空闲：改为先校验全部选中行，非法数据报错误而不是当空课表；原始作息字段先于兼容性校验。
- 配置保留组合身份：成员增删/成员新课程在事务内重新解析，事件观察者随课表与组合切换；组合删除立即使旧结果失效。
- 视口起止、自定义标记、草稿课程筛选与初始化状态全部经 SavedStateHandle 持久化，旋转/进程重建后正确恢复；集合序列化转义分隔符。
- 初始周与当前周改用校园时区（设备时区下校园周一可能仍是周日）；错误/加载态保留周导航；纯展示视口不再要求完整节次参与；5 分钟步进吸附不超出作息端点。
- 未知/隐藏占用打断合并（不再被当作空闲桥接）；仅 ≤20 分钟课间并入；末节 24:00 结束不再折算为 0 分钟；窄视口（<60 分钟）不被最小网格高度放大；明细缺失时段保持未知而不是伪造空闲。
- 存储的 BUSY 元数据与 FULL 快照不一致时，经共享 `matchesSnapshot` 校验拒绝构造来源与课程菜单。
- 整门课批量改时间按各次实际校园周一为基准偏移：非周一开学、设备非校园时区不再算错日期。

验证：`testDebugUnitTest`（含新增 19 项对比/批量编辑 JVM 回归）与 `assembleDebugAndroidTest` 通过；`TimetableComparisonRepositoryTest` 等插桩回归已编译未上设备。UI 旋转恢复、滚动与切周交互仍需真机确认。
